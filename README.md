# Splitkaro Chore Calendar

Build a mobile-first prototype called "Splitkaro Calendar", an extension of the existing Splitkaro expense-sharing app.

The feature helps flatmates coordinate household responsibilities through a shared weekly calendar.

For now, build only the main Calendar home screen.

Requirements:

Mobile app layout, optimised for a 390px-wide screen.

Use a clean, modern design inspired by Splitkaro's existing interface: white backgrounds, indigo/blue primary buttons, rounded cards and simple typography.

Bottom navigation with Home, Groups, Calendar, Analytics, Bills and Balances. Highlight Calendar as active.

Show a group name: "Flat 4".

Show a weekly calendar strip with days Monday to Sunday and the selected date highlighted.

Below it, show the selected day's task list.

Each task card should display task name, assigned flatmate, due time and status.

Include sample tasks: Laundry, Buy groceries, Take out garbage, Clean kitchen.

Display Pending, Done, Swapped and Overdue as distinct status labels.

Add a prominent floating or fixed "+ Add Task" button.

Include realistic sample flatmates: Muskan, Nandini, Mehak and Lakshay.

Use believable sample task data.

Keep the layout uncluttered and easy to navigate.

Use sample data only for now. Do not add authentication, backend, payment features or external integrations.

Make the interface feel like a real Indian shared-household management app, not a generic corporate task dashboard.
